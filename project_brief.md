# My agent: Event & Travel Planner (VoyageSync)
One-liner: A conversational agent that helps families and teams plan, visualize, and share upcoming trips and events with a catalog of curated activities, custom event banner visuals, and shared itineraries.

Tool coverage:
- Memory: Group destination, travel dates, attendee roster, dietary preferences, budget constraints, and activity preferences across conversations
- Tools: Look up attractions/activities, check weather forecasts, and retrieve/update itinerary schedules
- Catalog/UI: Scheduled daily activities, dining recommendations, and packing lists rendered as interactive cards and tables (A2UI)
- Image gen: Postcard-style trip banners, custom event invitation covers, and destination highlight visuals to share with family or team members
- Sandbox: Group budget/expense splitting calculations and travel timing estimates

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): Code sandbox for group expense splitting, Cloud Storage for sharing generated event banners, Cloud Trace for observability
